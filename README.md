# つづり — 回答を家族へ渡して、一冊の自分史に

APIキー・合言葉・ログインを用意せず、親が一問一答で思い出を残すサイトです。

## 親御さんの使い方

1. https://first-app-89fp.vercel.app/ を開き、お名前などを入力。
2. 基本36問に一問ずつ回答。短く答えても、分からない質問をスキップしても大丈夫です。
3. 希望した場合だけ、補足質問に最大10問まで回答（途中で終了可）。
4. 「回答ファイルを保存」でテキストファイルを端末に保存。
5. 保存したファイルをLINEやメールで家族に送る。対応ブラウザではファイル共有ボタンも使えます。

途中で閉じても、同じ端末・同じブラウザで続きから再開できます。途中の回答だけでも保存可能です。入力中にヘッダーの「回答を保存・送る」へ進んだ場合も、その入力をファイルに含めます。

## ファイルを受け取ったご家族の使い方

受け取った `.txt` を、今回のサイト作成を進めているChatGPTのチャットへ添付し、「この回答をもとに約5,000字の自分史に編集してください」と依頼します。

ファイルには基本情報、全36問の質問・回答、未回答とスキップの区別、任意の追加回答、以前の追加質問と回答、編集の依頼文が入っています。ChatGPTは本人の事実と言葉をもとに原稿へ編集し、ご家族と本人が確認して仕上げます。サイトで保存するファイルは完成した本ではなく、編集用の回答資料です。素材が少ない場合に、字数のために架空の出来事や感情を補わないよう依頼文に記載しています。

フッターの「ご家族向けの案内・サイトを送る」から、親御さんへ送る説明文とURLをコピーできます。コピーするだけで、メッセージの自動送信はしません。

## 保存とプライバシー

回答・下書き・スキップ・進み具合はブラウザのlocalStorageに保存します。回答をサーバーやAIサービスへ送る処理はありません。データを消した場合や端末・ブラウザを変えた場合は引き継がれないため、回答ファイルを保存して保管してください。共有端末では他の利用者も同じ回答を閲覧できます。

ファイルの共有は、利用者がブラウザの共有画面で送り先を選んだ場合だけ行います。共有画面を使えない端末でも、ダウンロードしたファイルを手動で添付できます。親御さんとご家族の端末が自動で同期される機能はありません。

検索結果への掲載を拒否する`noindex`タグを維持しています。これは閲覧制限やアクセス認証ではありません。

## 任意の追加質問

基本36問を終えたあと、希望した場合だけ、素材が少ない章から用意された補足質問を選びます。未回答だけの章は対象外にして、スキップした話題を無理に掘り返しません。AI通信は不要です。最初の計画を保存し、途中終了・再読み込み後も質問を増やさず、全体で最大10問に収めます。回答のたびに追い質問を出すことはありません。

以前の回答、任意の補足計画、原稿データは消さずに引き継ぎます。旧版の本の画面を開いていた場合も、回答ファイルを保存する画面へ移行します。

## 開発・公開

Node.js 24、外部npm依存なし。

```sh
npm run dev
npm test
npm run build
```

開発サーバーは`scripts/dev-server.js`（ポート3000、`PORT`で変更可）。`dist/`は静的サイト、`dist/tsuzuri.html`は単体HTML版、`docs/index.html`はGitHub Pages版です。ビルド時にフロントエンドの構文も確認します。

Vercelは`vercel.json`の静的ビルドのみを使用します。AIキーの設定やサーバーレス関数は不要です。mainへpushすると、接続されたVercelプロジェクトで再デプロイされます。旧AI実装とそのテストは移行資料としてリポジトリに残していますが、サイトから呼び出さず、公開ビルドの対象にも含めません。

## 検証

基本情報・一問一答・36問での終了・途中再開・スキップ・任意の追加質問・回答ファイルの中身・日本語ファイル名・案内文コピー・スマートフォン表示を確認。共有画面はテスト用のブラウザ応答で検証し、実際のメッセージは送っていません。端末やLINE内ブラウザによって保存画面や共有先の表示は異なります。

## ダウンロードできない場合の取り出し

保存画面に「保存できないとき：全文を表示・コピー」を常設しています。ファイルAPIがエラーになる場合は、この画面を自動で開きます。表示内容はダウンロードする回答ファイルと同一で、全文コピーと手動の全文選択を用意しています。クリップボードが拒否されても選択した文章を端末の操作でコピーできます。

ダウンロードの成否にかかわらず、ブラウザ内の回答を削除する処理はありません。ただしOSがファイル保存を完了したかどうかをサイトから確認することはできないため、ファイルを実際に開いて内容を確認してください。ブラウザの保存データを消したり、別端末・別ブラウザへ移ったりすると引き継がれません。保存に失敗した場合は、回答したブラウザ内でまず全文を取り出してください。

ブラウザ試験で、36問すべて・長い回答・任意の追加回答・基本情報を実際のダウンロードファイルで確認し、保存APIのエラー、コピー拒否、手動選択、再読み込み後にも回答が残ることを確認しています。端末ごとの保存動作そのものを一律に保証するものではありません。
