# つづり — 親の人生を、一冊の本に

親が自分のペースで質問に答え、人生の思い出を本として残す日本語のフロントエンド試作品です。

## 開発

Node.js 24 で動作確認済み。外部の npm 依存関係はありません。

```sh
npm run dev
```

ポート 3000 で起動します。`PORT` 環境変数で変更できます。

```sh
npm test
npm run build
SERVE_DIST=1 npm start
```

ビルド済みの `dist/` は静的サイトとして配信できます。Google Fonts が使えない場合は端末の日本語フォントに切り替わります。イラストはローカルファイルです。

`npm run build` は単体で開ける `dist/tsuzuri.html` も生成します。このファイルをダウンロードしてブラウザで開けば、サーバーなしで利用できます。ソースの `index.html` を直接開くと JavaScript のモジュール制限で表示されないため、単体版を使うか、開発サーバーを起動してください。クラウド環境の localhost は利用者の PC の localhost と異なるため、PC から直接は接続できません。

## GitHub Pages で公開

`npm run build` は GitHub Pages 用の `docs/index.html` も生成します。リポジトリの Settings → Pages で「Deploy from a branch」、ブランチ `main`、フォルダ `/docs` を選びます。公開設定とデプロイが完了すると、通常は `https://yutakehub.github.io/first.app/` で開けます。

サイトはブラウザ内保存の試作品です。利用者が入力した回答はリポジトリへ保存されません。公開後にコードを変更したときは、再度ビルドして `docs/` の更新も一緒に反映してください。

## 機能

- 6章・18問のガイド付きインタビュー
- お名前、生まれた年、生まれた場所、幼い頃の家族を登録してからインタビューを開始
- 回答に年代を添えられる人生年表（未入力の年代を補完・捏造しません）
- 回答・入力途中の下書きのブラウザ内保存、再開、質問のスキップ
- 著者名の設定、回答数に連動した進捗、本のプレビュー
- 回答の再編集、テキスト形式で本をダウンロード
- スマートフォン対応、キーボード操作、ダイアログ、読み上げ用ラベル

質問は定義済みで、回答はそのまま章にまとめます。AIによる追加質問・文章の編集、アカウント、家族間共有、クラウド保存、PDFや印刷にはまだ対応していません。回答は外部へ送信しません。ブラウザのデータを消すと保存した回答も失われるため、ダウンロードして保管してください。共有端末では保存した回答を別の利用者も閲覧できます。
