# つづり

親が一問一答で人生を振り返り、最後にAIが一冊の自分史にまとめるサイト。

## 進め方

1. お名前・生年・出生地・家族を登録。
2. 決まった36問に、一問ずつ回答。保存すると即座に次へ進み、章の境目でも止まりません。回答のたびに追加質問は出さず、章ごとの原稿確認もありません。いつでも前の質問へ戻れ、分からない質問はスキップできます。
3. 36問目のあとに回答一覧と「AIで本にする」を表示。必要なら回答を修正できます。修正後は一覧に戻り、残りの質問を繰り返すことはありません。もう少し詳しく話したい場合だけ「もう少し詳しく答える」を選べます。
4. 一度ボタンを押すと、AIが全回答を約5,000字を目指してまとめます。内部では回答のある章ごとに生成してから一冊に結合するため、利用者による章ごとの操作は不要です。
5. 最後に本全体の事実と表現を確認・修正し、ダウンロード。

素材が少ない場合は短めの本として完成させ、質問に戻しません。字数のための創作・繰り返しをしないようAIに指示します。約5,000字は目標であり、短い回答だけでその分量を保証するものではありません。

回答・入力途中の文章・スキップ・現在の質問・作成した本はブラウザ内に保存します。作成途中の章も保存するため、通信エラー後の再試行では完成した章を再生成しません。以前の回答、追加回答、章の原稿も保持します。過去の追加回答は本の素材として利用できますが、回答中に新しい追加質問を自動で出すことはありません。

別端末への同期、ログイン、家族間共有、PDF、音声入力は未対応です。ブラウザのデータを消すと記録が失われるため、本はダウンロードして保管してください。

## 開発

Node.js 24、外部npm依存なし。

```sh
npm run dev
npm test
npm run build
```

開発サーバーは`scripts/dev-server.js`でポート3000（`PORT`で変更可）。`dist/`は静的サイト、単体版は`dist/tsuzuri.html`、GitHub Pages版は`docs/index.html`です。静的配信だけではAI処理は動きません。

## Vercel

1. GitHubの`yutakehub/first.app`をImport。
2. リポジトリの`vercel.json`を使用。画面を`@vercel/static-build`、APIを`@vercel/node`で明示的に分離します。開発サーバーは起動しません。
3. Environment Variablesに以下を設定し、DeployまたはRedeploy。
   - `MEMOIR_AI_KEY`: OpenAI APIキー。秘密情報として保存し、チャットやGitへ書かない。
   - `MEMOIR_ACCESS_CODE`: 家族にだけ伝える、十分に長い合言葉。
   - `MEMOIR_AI_MODEL`: 任意。初期値`gpt-4.1-mini`。
4. サイトの「AI編集の設定」に、家族の合言葉を入力。

基本36問の回答中はAI通信をしません。任意の補足質問を希望した場合のみ`/api/supplement`で質問を計画します。最後の`/api/book`が合言葉を確認してOpenAIへ接続します。APIキーはフロントエンドに含めません。合言葉はタブのsessionStorageに保存します。サーバーは回答や原稿を保存しません。簡易制限はインスタンスごとに12回/分です。一般公開サービスには、個人ごとの認証・クラウド保存・永続的な利用制限が別途必要です。

`/api/status`は設定の有無だけを返します。旧版との互換性のため`/api/draft`・`/api/followup`も残していますが、新しい画面からは呼びません。

AI生成時に基本情報・回答・以前の追加回答を外部AIサービスへ送信します。本人が述べていない事実・感情を創作しないよう指示しますが、事実性を保証するものではなく、完成原稿の確認が必要です。

## 検証の範囲

ローカルテストとブラウザで、36問で終了すること、回答中のAI呼び出しがないこと、途中再開、スキップ、一括本づくり、原稿編集・確認・ダウンロードを検証。AIの応答はテスト用データを使用しています。実際のAI品質・本番接続は、Vercelでキーを設定して検証する必要があります。

## 任意の追加質問（全体で最大10問）

基本36問を終えた後、希望したときだけ補足できます。そのまま本にするボタンは常に残します。AI接続時は、既存の回答とスキップした話題をもとに、不足する情報を聞く質問を0〜10問だけ一度に計画します。既存の回答にない人物や感情を前提にせず、スキップした内容を無理に聞き直さないよう指示します。不要と判断した場合は0問で終わります。AI未接続時は、素材が少なく、少なくともひとつ回答がある章に用意された補足質問を選びます。

計画はブラウザに保存して再作成しません。回答・スキップ・中断・再読み込みで質問数が増えず、一つの人生につき最大10問です。各問は一問一答で追加の追い質問は出しません。途中でやめても、答えた分だけを本の素材に含めて本づくりへ進めます。追加回答を変更すると本の元資料が変わったことを検出します。

AIの質問選定品質と公開先での通信はキー接続後に確認が必要です。ローカルでは10問上限、途中再開、任意性、回答を本に含める動作をテスト用のAI応答で確認しています。
